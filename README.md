## 为什么做净卷宝？

市面传统拍试卷 App 普遍存在三大痛点：
1. **包年订阅刺客**：动辄 ¥168/年自动续费；
2. **打印没法直接做题**：机械抠图导致错题导出文字重叠，填空题、解答题行距过窄，孩子打印出来根本没有演算与书写空间；
3. **开屏摇一摇广告**：给孩子打卷子时稍晃手机就跳去第三方购物页。

**净卷宝（PaperClean）** 采用 **100% 浏览器本地像素级图像引擎**（无后端上传、零广告）：
- **自适应分块纸张底色漂白**：消除夜晚台灯斜拍阴影与黄暗卷面，还原纯白打印底，同时增强黑色铅印题干锐度；
- **双通道笔迹精准擦除**：HSV 色彩分离抹除红笔叉号/批改、蓝笔圆珠笔作答与荧光笔；对比度阈值滑块分离浅灰铅笔草稿 + 矩形留白橡皮框精修；
- **填空/解答题加宽留白插入器**：一键在任意题目下方撑开纯白书写空白带（支持浅灰虚线辅助线）；
- **A4 防重叠智能分页**：自动检测行间空白切分，直连 AirPrint 与家庭无线打印机。
